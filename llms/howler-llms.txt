# Howler

> Howler is a South African event technology platform that consolidates ticketing, RFID cashless payments, and vendor/access management into one system. Its consumer-facing Howler API v3 covers authentication, tickets, cashless tags, top-ups, and cashout, and a Howler Webhooks v1 surface pushes ticket, event, and payment events to partners.

## APIs
- [Howler API v3 (consumer portal) — OpenAPI](https://developer.howler.co.za/api-docs/v3/consumer_portal_swagger.yaml): 67 operations across OAuth, tickets, cashless tags, top-up, cashout, events, users, and bank accounts. Base server https://www.howler.co.za/api/v3/consumer_portal
- [Howler Webhooks v1 — OpenAPI](https://developer.howler.co.za/api-docs/webhooks/webhooks_swagger.yaml): Ticket, Event, and Payment webhook events delivered to partner endpoints.
